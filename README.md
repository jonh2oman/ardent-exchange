# 🪙 Ardent Exchange v1.1.0

### **Tactical Economy & POS Management System for Cadet Units**

Ardent Exchange is a premium, full-stack banking and Point of Sale (POS) application designed specifically for the Royal Canadian Sea Cadet Corps (RCSCC) and other cadet units. It provides a secure, glassmorphic interface for managing internal unit currency ("Ardent Dollars"), canteen inventory, and cadet achievement rewards.

---

## 🎖️ Key Features

### 🛒 **Point of Sale (POS) Hub**
*   **Real-time Inventory**: Seamlessly process sales for Canteen (snacks/drinks) and Swag (unit hoodies/coins).
*   **Cadet Integration**: Search for cadets by name and instantly deduct purchases from their digital balance.
*   **Stock Tracking**: Automatic inventory alerts when products run low.

### 🏛️ **Officer Command Ledger**
*   **Achievement Rewards**: Officers can instantly reward cadets with currency for marksmanship, dress, or parade performance.
*   **Audit Trail**: A permanent, secure transaction history for every dollar earned or spent.
*   **Global Reset**: Ability to reset the economy for a new training year with a single click.

### 👤 **Digital Identity & Profiles**
*   **Rank Management**: Cadets can manage their own profiles, including updating their current rank (Cpl, Sgt, WO, etc.).
*   **Tactical Avatars**: A selection of military-themed icons (Ships, Planes, Shields) to replace generic user initials.

### 🎨 **Military Theme Engine**
Full support for specialized color palettes designed for different environments:
*   **Sea**: Deep Navy & Cyan (Maritime operations)
*   **Air**: Sky Blue & Silver (Aviation operations)
*   **Army**: Olive Drab & Desert Tan (Land operations)
*   **Night Vision**: High-contrast tactical HUD mode (Neon Green/Black)
*   **Classic**: Light, Dark, and System modes.

---

## 🛠️ Technology Stack
*   **Frontend**: Vite + Vanilla JavaScript (Modern, ultra-fast performance).
*   **Backend**: Supabase (PostgreSQL) for real-time data sync and security.
*   **Security**: Row-Level Security (RLS) policies and domain-restricted registration.
*   **Deployment**: Fully automated via GitHub Actions to GitHub Pages.

---

## 🛡️ Security Notice
Registration is strictly restricted to official unit domains (e.g., `@cadets.gc.ca`). The application includes a mandatory legal disclaimer regarding its status as a non-official DND/CCO tool.

---

## 🚀 Getting Started
1. **Authorize**: A staff officer must pre-authorize your email in the Ledger.
2. **Register**: Sign up using your official unit email at the login screen.
3. **Engage**: Start earning Ardent Dollars through unit achievements!
